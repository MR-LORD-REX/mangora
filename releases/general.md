# Planned & in progress

**Updated 2026-10-10**

Small changes and work in flight that has not shipped in a versioned release yet.

- **Share links.** A share button in the viewer that produces a link to this site, opening the manga directly
  in the app when it is installed.
- **In-app updates.** Check for a new release from Settings and install it without leaving the app, with a
  clear prompt if the install permission has not been granted.
