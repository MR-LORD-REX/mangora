# v0.0.1 — First public beta

**Released 2026-10-10**

The first public build of Mangora: eight sources, one library, one reader — with offline downloads,
text detection and AI translation built in.

## Highlights

- **Eight sources in one library.** MangaDex, MangaKatana, MangaGeko, Comix, BrainRot, Philia Scans,
  Manhwa18 and NHentai all open in the same reader with the same controls.
- **A real reader.** Vertical scroll, horizontal scroll, vertical paged and horizontal paged, with tap-zone
  page turns, rotation lock, keep-screen-awake and auto-scroll.
- **Tiled decoding for long strips.** Very tall pages render through native subsampling instead of choking.
- **Offline downloads.** Chapters are written as `.cbz` archives into a folder you pick once. One global
  queue, per-source and per-page concurrency, a Wi-Fi-only mode that resumes on its own, and a foreground
  notification with pause / resume / cancel.
- **Read offline, fully.** Downloaded series stay browsable with no connection, with search, sort and
  scanlation-group filters intact.
- **Text detection and OCR.** YOLO finds the speech bubbles; OCR runs either on-device (ExecuTorch) or
  through a cloud endpoint you configure.
- **AI page translation.** Translate a page with Gemini, batched with previous pages attached as story
  context, drawn back over the art as an overlay with adjustable text scale.
- **Multi-library organization.** Unlimited named libraries plus two system libraries, with unread badges
  and in-progress markers.
- **Backup and restore.** The whole database exports to a single `.db` file in your chosen folder.

## Install

ARM64 Android 7.0+ only — 32-bit ARM is not supported.

## Known limitations

- Live browse and search feeds are not cached for offline use; only downloaded chapters read offline.
- Comix downloads need the app in the foreground, because its page URLs depend on the in-app browser session.
- Update checks are not wired up yet.
