# v0.0.3 — Extensions, AVIF pages, reader polish

**Released 2026-10-18**

Third public release. The big change is the source model: Mangora now runs Mihon/Keiyoushi
extensions, so the catalogue is whatever you install, and every source opens through the same
manga page, reader, translator and download queue. This release also adds AVIF page support,
reader color controls, and a full translation-overlay typography pass.

## Highlights

- **Bring your own sources.** Add a Mihon-compatible repository `index.json`, browse its
  catalogue, install an extension APK, and its sources appear in Browse. Mangora hosts the
  Tachiyomi/Keiyoushi source API 1.6 in-process; there is no bundled catalogue and no hard-coded
  source list.
- **One shared source flow.** Extension results use the same manga page, chapter list, reader and
  downloader as everything else. The old built-in provider screens are gone, and legacy database
  rows remain readable but inert.
- **Cloudflare that keeps working.** Managed challenges are solved in an off-screen WebView, and
  the resulting cookies are shared with the native source client. Page images and downloads run
  through the source's own OkHttp client, so per-source headers, Cloudflare cookies, random user
  agents and image interceptors all apply.
- **Extension downloads and offline reading.** Chapter pages are resolved once through the
  extension, fetched through its image client, and stored as `.cbz` archives in your chosen
  folder. The queue, Wi-Fi-only mode, foreground notification and offline reader work with
  extension sources. Download paths now handle bracketed titles and other URI-hostile names.
- **AVIF pages work.** Pages served as AVIF (for example from Atsumaru's CDN) are decoded by a
  native libavif/AOM transcoder and cached as PNG, so the reader, YOLO detection and OCR all see
  normal images instead of failing to decode.
- **Reader controls.** Custom brightness (0–200%), grayscale strength, inversion and an RGB tint
  are applied to the page image only, keeping translated overlays readable. Grayscale, inverted
  and custom color are mutually exclusive. The chapter download button moved into the reader
  header, and the title scrolls horizontally in its fixed slot.
- **Translation overlay polish.** Overlays stay locked to the page while pinch-zooming. Joint
  speech bubbles split into one slot per inner text cluster, duplicate detections are dropped,
  and a paste is skipped when another region already occupies that box.
- **Overlay typography.** Bubble text uses 85% of the detected bubble area and auto-fits the
  largest readable font. Overlay settings now include Default / Comic Neue / Bangers / Chewy
  fonts, a weight slider, a size scaler and RGB text color, all persisted. Non-Latin target
  scripts fall back to the system font.
- **Source organization.** Browse > Sources groups installed sources into Pinned, Last used,
  English, Multi and Other. Pin any source from the list; pins stay above every language group.

## Install

ARM64 Android 7.0+ only — 32-bit ARM is not supported.

## Known limitations

- Extension compatibility depends on the host API. Extensions built for Mihon source API 1.7+
  may fail until the host is updated.
- Interactive Cloudflare Turnstile challenges cannot be completed headlessly; only managed,
  non-interactive challenges are solved automatically.
- AVIF support decodes the first frame. Animated AVIF pages render as a still image.
- Debug builds (`expo run`, dev client) use a different signing key, so App Links may open the
  landing page instead of the dev app. Release builds auto-verify.
