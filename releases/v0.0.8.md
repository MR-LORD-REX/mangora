# v0.0.8 - More translation choices and better pre-translation

**Released 2026-11-02**

Mangora 0.0.8 adds a choice of region detection models, lets you read cached
translations while another chapter is being pre-translated, and improves
pre-translation notification controls. It also introduces a configurable
OpenAI-compatible translation endpoint and the new official website.

## What's new

- **Two region detection models.** Choose **RT-DETR Comic v4** for higher-quality
  detection boxes covering speech bubbles, text inside bubbles, and free text.
  Choose **Manga109 segmentation** for bubble masks that support more precise
  text erasing and fitting. Mangora runs one selected detector per page. Download
  the model you want in **Settings > Models** before using it.
- **Read while pre-translation continues.** Cached translated pages can render
  in the reader while another chapter is being pre-translated. If a reader page
  needs new detection or OCR, that work gets priority after the current vision
  operation finishes. The pre-translation queue still processes one chapter at
  a time and pauses when Mangora leaves the foreground.
- **Fixed pre-translation notification controls.** Running jobs show **Pause**
  and **Cancel**; paused jobs show **Resume** and **Cancel**. Actions apply to the
  chapter shown in the notification. When the queue finishes, the notification
  shows a completion or failure summary without action buttons.
- **OpenAI-compatible AI translation.** Mangora can translate recognized text
  through an OpenAI-compatible endpoint. The endpoint and model are prefilled
  for Gemini, so to use it, add your API key in **Settings > Translation** and
  choose **AI Translation** in the reader. You can also configure another
  compatible service or a local network endpoint.
- **New official website.** Visit [mangoraweb.vercel.app](https://mangoraweb.vercel.app/)
  for Mangora information, downloads, and release updates.

## Good to know

- Region detection and OCR models are downloaded separately; they are not
  included in the APK.
- On-device detection and OCR process page images locally. Online translation
  sends recognized text to the translation service you select.
- For the PC app, a local PC-to-Android translation bridge, and screenshot-based
  app guides, see the [Planned section](general.md#planned).

## Install

Choose the Android 7.0+ APK that matches your device:
`arm64-v8a` for 64-bit ARM or `armeabi-v7a` for 32-bit ARM.
