# v0.0.6 - A smoother reader, cleaner translations, download recovery, and 32-bit ARM support

**Released 2026-10-21**

Mangora 0.0.6 improves reader usability, creates cleaner translation overlays,
adds 32-bit ARM device support, updates on-device text recognition, and makes
it easier to restore a download library if the app's local index is lost.

## What's new

- **A more usable reader.** More flexible reading controls make it easier to
  choose a layout, adjust page-turn tap zones, and tune image presentation with
  options such as split wide pages, border cropping, rotation, and display
  filters.
- **Cleaner, more natural-looking translations.** Advanced bubble masks guide
  text removal while preserving the bubble outline, helping translated text
  blend more naturally into the original artwork.
- **Recover your download library.** Settings > Downloads can rebuild the
  app's download list from `downloads/metadata/metadata.json`. Mangora checks
  each listed archive before restoring it and shows progress and any chapters
  it could not recover. Recovery needs the metadata file; without it, Mangora
  will not guess chapter identities from filenames.
- **Safer download checks and cleanup.** Completed archives are checked for
  valid page images before they are listed as downloaded. Bulk recovery and
  deletion show progress; deletion leaves files that cannot be identified by
  the catalog untouched.
- **Updated on-device OCR models.** PP-OCRv6 is available for Japanese,
  Chinese, and English; PP-OCRv5 covers Korean and Latin-script languages.
  Recognition uses text-line detection and batching for clearer processing.
- **More resilient AI translation.** With Auto model switch enabled, Gemini
  translation can retry a rate-limited request using the other available
  model. The setting can be turned off if you prefer to keep requests on the
  selected model.
- **32-bit ARM device support.** Mangora is now built for both 64-bit ARM
  (`arm64-v8a`) and 32-bit ARM (`armeabi-v7a`) Android devices. Download the
  APK that matches your device architecture from the release assets.

## Good to know

- Recover downloads relies on the `metadata.json` file in the selected
  downloads folder. Keep that file with the chapter archives if you move or
  back up the folder.
- Translation still depends on the OCR model selected for the page language.
  Download the relevant model in Settings > OCR models before translating.
- Mangora remains Android-only. Online translation sends recognized text to
  the selected translation service; OCR itself runs on-device.

## Install

Android 7.0+ (API 24+) - install the `arm64-v8a` APK on 64-bit ARM devices or
the `armeabi-v7a` APK on 32-bit ARM devices.
